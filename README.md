# homebrew-agentman

Homebrew tap for [agentman](https://github.com/lenajeremy/agentman) — watch your
coding agents from your phone and answer them when they get stuck.

```bash
brew install lenajeremy/agentman/agentman
```

## About this tap

The formula in `Casks/` is generated by
[GoReleaser](https://goreleaser.com) when a version tag is pushed to the main
repository. Do not edit it by hand — the next release will overwrite it.

agentman ships as a **Cask** rather than a Formula because it distributes
prebuilt binaries; GoReleaser deprecated the Formula path for that. Anyone who
installed the old Formula is migrated automatically by `tap_migrations.json`.
